# SSC Calculation Mastery — Mobile PWA

This package contains the 60-day SSC Calculation Mastery web app.

## Install on Android
1. Host this folder on HTTPS (GitHub Pages, Netlify, Vercel, etc.).
2. Open the hosted `index.html` in Chrome.
3. Use Chrome's **Install app** / **Add to Home screen** option.
4. Launch it from the home-screen icon.

## Included
- Days 1–60
- Premium mobile UI
- Day/Night theme
- Tests, timer, results, errors, analytics and progress
- PWA manifest
- Service worker for cached/offline use after first successful load
